## Research routing — three-tier guidance

Agents have clear guidance on which research tool to use for each type of question.

### Confirmed behaviors

- **AI-WORKFLOW.md has a "Choosing the right research tool" section:**
  The file includes a three-tier table distinguishing inline (quick factual), /deep-research
  (background knowledge, landscape survey), and /spike (feasibility or approach that gates a
  build decision). The decision rule — "does the answer determine what you build next?" — appears
  in the section. The section lives between the work-state table and the orchestration tool section.

- **spike/SKILL.md explicitly distinguishes spike from /deep-research:**
  The "What this is not" section includes an entry stating that spike is not general background
  research — /deep-research covers knowledge-building that doesn't gate a build decision.
